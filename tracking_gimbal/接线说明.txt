二维云台 位置控制程序 接线说明
================================

芯片：TI MSPM0G3507
程序功能：让云台 X/Y 两个轴转到指定角度（位置控制）

----------------------------------------------------
一、步进电机（两个轴：X 轴 + Y 轴）
----------------------------------------------------
  X轴 STEP（脉冲）->  PA24   发给 X 轴电机驱动器的脉冲
  X轴 DIR （方向）->  PA13   控制 X 轴正转/反转
  X轴 EN  （使能）->  PA16   使能或锁死 X 轴电机
  Y轴 STEP（脉冲）->  PA22   发给 Y 轴电机驱动器的脉冲
  Y轴 DIR （方向）->  PA14   控制 Y 轴正转/反转
  Y轴 EN  （使能）->  PA17   使能或锁死 Y 轴电机

----------------------------------------------------
二、其他
----------------------------------------------------
  按键 KEY      ->  PA18   单击=正转一步角度；双击=反转一步角度
  指示灯 LED    ->  PB9    板载 LED，程序里每 1 秒闪一次
  串口 TX       ->  PA10   接 USB 转串口，往电脑打印 X/Y 角度信息
  串口 RX       ->  PA11
  调试 SWDIO    ->  PA19   烧录/调试用的固定接线（连调试器）
  调试 SWCLK    ->  PA20   烧录/调试用的固定接线（连调试器）

----------------------------------------------------
通俗说明
----------------------------------------------------
1. 这个程序控制"转多少角度"：程序会计算目标角度对应多少步脉冲，
   然后发够脉冲就停，云台就停在目标位置。
2. 步进电机是 16 细分，200 x 16 = 3200 个脉冲 = 一整圈。
3. X/Y 两个轴各自独立控制，所以云台能同时左右、上下转。
4. 串口打印的格式类似：
   X:angle=45.0/45.0 deg ... Y:angle=30.0/30.0 deg ...
   （当前角度 / 目标角度，单位：度）
